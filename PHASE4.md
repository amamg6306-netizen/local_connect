# LocalConnect Phase 4

Phase 4 adds database-backed engagement features on top of Phases 1–3.

## Implemented
- Reviews and 1–5 star ratings.
- Review eligibility enforced by completed service request ownership.
- One review per service request enforced by database UNIQUE constraint.
- Provider/business average ratings and public review lists.
- Customer favorites with AJAX add/remove and duplicate prevention.
- Favorites dashboard.
- Database notifications inbox, unread counter, mark-read and mark-all-read.
- Notifications are generated by request workflow and new reviews.
- Role authorization, prepared statements, CSRF checks and escaped output retained.

## Existing database upgrade
Import `database/phase4_migration.sql` once after Phase 3. The core Phase 4 tables already exist in the forward-compatible full schema; the migration adds query indexes.
