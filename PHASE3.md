# LocalConnect Phase 3

Implemented: direct service requests, Post a Requirement, matching available requirements, provider/business response, Accept/Reject, In Progress, Completed/Cancelled, customer cancellation, status history, authorization, CSRF protection, and database notifications generated by request actions.

## Existing Phase 2 installation
Import `database/phase3_migration.sql` once. Do not re-import the full database SQL or your existing data will be reset.

## Fresh installation
Import `database/localconnect_db.sql`. Phase 3 works with the existing request tables in that schema; the Phase 3 migration only adds optimization indexes.
